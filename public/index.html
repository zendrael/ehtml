📋 Usage Instructions

To use this library in your project:

  1. Compile the Pascal unit:
    pas2js -Jirtl.js -Jc ehtml.pas
  2. Include the generated JavaScript file in your HTML:
    <script src="ehtml.js"></script>
  3. Use data-* attributes in your HTML elements:
    • data-get="/api/endpoint" - GET request
    • data-post="/api/endpoint" - POST request
    • data-put="/api/endpoint" - PUT request
    • data-delete="/api/endpoint" - DELETE request
    • data-patch="/api/endpoint" - PATCH request
    • data-target="#element-id" - Where to place response
    • data-swap="innerHTML|outerHTML|beforebegin|afterbegin|beforeend|afterend|delete|none" - How to insert content
    • data-trigger="click|change|submit|load|focus|blur|keyup|keydown|mouseover|mouseout" - What event triggers the request
    • data-headers='{"Custom-Header": "value"}' - Custom headers (JSON format)

Key Features:

  • ✅ Automatic initialization on DOM ready
  • ✅ Form serialization for POST/PUT/PATCH requests
  • ✅ Multiple swap strategies for content insertion
  • ✅ Custom event triggers
  • ✅ Automatic processing of dynamically loaded content
  • ✅ Error handling and logging
  • ✅ Support for custom headers
  • ✅ Compatible with all modern browsers
